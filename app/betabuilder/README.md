# DEPRECATED CLASSIC UI

The `/betabuilder/*` route tree is the original Brewing.It UI, kept as a reference implementation during the HopSkip migration. Do not modify; do not import from this tree outside `app/betabuilder/`. New features ship to the HS-native equivalents at the root URL (HopSkip).

See [/HOPSKIP_MIGRATION_PRD.md](/HOPSKIP_MIGRATION_PRD.md) for the migration plan.
